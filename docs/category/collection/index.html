Collection

REST APIs that allows G&L collectors to be triggered.

📄️Collect Accounts

Run one or more account collectors.

📄️Collect App Metadata

Run one or more application metadata collectors.

📄️Collect Data Access

Run one or more data access collectors.

📄️Collect Entitlements

Run one or more account collectors.

📄️Collect Identities

Run one or more identity collectors.

📄️Collect Multi-App Entitlement Collector

Run one or more multi-app entitlement collectors.

📄️Collect Roles

Run one or more role collectors.

📄️Delete Collector

Delete a collector.

📄️Delete Pending Collections

Delete all pending collections that are queued for execution. Note that executing runs cannot be deleted currently.

📄️Delete Pending Run

Delete a single run that is queued for execution. Note that executing runs cannot be deleted currently.

📄️Get Run Status

Determine the status of a given run (collection or review generation).

📄️Unify

Run a unification on collected identities.
