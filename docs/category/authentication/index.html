Authentication

📄️Get Login Instructions

Obtain the user name label, password label, and login page message that are displayed on the login page. Depending on the system settings, all of these results could contain HTML and/or JavaScript. If HTML or JavaScript exists, it will be returned in the output.

📄️Login as Trusted Application

Create a token for a trusted application, which can then be passed to other web services.

📄️Login User

Create a user session token, which can then be passed to other web services.

📄️Logout User

Deactivate a session token retrieved from loginUser.
