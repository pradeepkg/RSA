Architecture and Integration Principles

🛡️

Zero Credential Caching

Credentials are never stored in the RSA G&L database. Collectors and connectors retrieve secrets dynamically over HTTPS at job execution.

🔄

Automatic Rotation Alignment

Password rotation schedules enforced by the vault take effect immediately without requiring configuration changes in RSA G&L.

🧩

Standardized Vault SPI

Plugins integrate through RSA G&L's BaseVaultClient framework, providing uniform configuration testing, credential resolution, and error diagnostics.
