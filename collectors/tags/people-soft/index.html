Oracle PeopleTools (PeopleSoft)✓ Verified

October 2, 2023 · 4 min read
Pradeep Kadambar
Creator
Oracle PeopleTools is the development and runtime toolset for Oracle PeopleSoft applications such as HCM, CRM, and EPM. User profiles and roles are stored in the PeopleTools security tables. RSA G&L collects accounts and roles directly from these tables with a database collector.
